# Madina AI Agent

Madina is a Telegram AI assistant built with Python. It supports text chats, voice messages, OpenRouter Gemini AI, STT, TTS, and SQLite-based memory.

## Quick start

1. Create a virtual environment
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

2. Install requirements
   ```bash
   pip install -r requirements.txt
   ```

3. Copy environment variables
   ```bash
   cp .env.example .env
   ```

4. Fill in real values in `.env`:
   - `TELEGRAM_BOT_TOKEN`
   - `OPENROUTER_API_KEY`
   - `OWNER_TELEGRAM_ID`
   - optional: `ALLOWED_TELEGRAM_IDS`

5. Run the bot
   ```bash
   python main.py
   ```

## Commands

- `/start`
- `/help`
- `/voice_on`
- `/voice_off`
- `/text`
- `/language uz|ru|en`
- `/clear`
- `/status`

## Notes

- Only `OWNER_TELEGRAM_ID` can access the bot by default.
- Other user IDs can be added with `ALLOWED_TELEGRAM_IDS` later.
- FFmpeg must be installed for voice conversion.
- Use Linux/macOS: `apt-get install ffmpeg` or `brew install ffmpeg`.
